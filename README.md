# Hello, I am Rifat

I am a civil engineering and media professional in Dhaka, Bangladesh. I make promos, titles and motion graphics, and I build small Windows tools for the parts of that work that should not take
so long.

I am not a programmer by training. I design the tool, decide how it should behave, and
build it with the help of an AI coding assistant, then test it on real client work before
sharing it.
